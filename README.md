# DriveProfit — مساعد الكابتن

تطبيق عربي RTL للسائقين في مصر. الواجهة مشتركة بين معاينة الويب وتطبيق أندرويد باستخدام **React + Capacitor**، مع خدمات Android أصلية بلغة Java للتتبّع وقراءة العروض. لا يحتاج إلى حساب أو مفاتيح API. الشعار مأخوذ من الصورة المرفقة، وصورة الموتوسيكل توضيحية وليست صورة مواصفات معتمدة للموديل.

## تشغيل الواجهة

يلزم Node.js 22 وnpm.

```bash
npm ci
npm test
npm run dev
```

لبناء ملفات الويب الثابتة: `npm run build` (الناتج في `dist/`). تتطلب واجهة الموقع الجغرافي HTTPS أو localhost وصلاحية من المستخدم. إذا حجبت المعاينة المضمّنة صلاحية الموقع، افتحها في تبويب مستقل. لا يعمل تتبّع الويب بشكل مضمون بعد قفل الشاشة.

## بناء نسخة أندرويد وتثبيتها

يلزم Android Studio وJDK 21 وAndroid SDK 35. الحد الأدنى Android 6 (API 23).

```bash
npm ci
npm run android       # يبني الواجهة وينسخها إلى مشروع Android
npx cap open android # اختر جهازاً ثم Run
```

أو من سطر الأوامر بعد ضبط `ANDROID_HOME`:

```bash
cd android
./gradlew testDebugUnitTest assembleDebug
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

على Windows استخدم `gradlew.bat`. بعد تعديل الواجهة كرّر `npm run android`. يتضمن المستودع سير عمل GitHub Actions لبناء APK تجريبي وتشغيل الاختبارات عند الدفع؛ هذا ليس إصدار متجر موقّعاً. لم يُبنَ APK أو تُختبر الخدمات على جهاز فعلي في جلسة التطوير الحالية.

## أول رحلة

1. من **مركبتي** اختر الموديل والبنزين. الاستهلاك المبدئي تقديري؛ صحّحه بنتائج التفويل الفعلي. من **الإعدادات** أدخل البنزين المتاح في بداية الرحلة، وحدّ السرعة ونسبة احتياطي الصيانة.
2. في **حاسبة الرحلة** أدخل كامل المسافة التي ستقودها، بما فيها الوصول للراكب إن أردت احتسابها. تعرض الحاسبة الوقود والصيانة والصافي، وتحذيراً إذا كان الصافي سالباً.
3. اضغط **بدء رحلة جديدة** والتطبيق ظاهر. على أندرويد اسمح بالموقع الدقيق، وبالإشعارات على Android 13+. يبدأ `location` foreground service بإشعار مستمر. لا يُطلب موقع دائم ولا تبدأ الخدمة عند إقلاع الهاتف.
4. سجّل الأجرة الفعلية عند **إنهاء الرحلة**. يتوقف GPS وتُحفظ المجاميع محلياً. إعدادات المركبة والأسعار مثبتة عند البداية لحسابات تلك الرحلة. يحتفظ المسار بآخر 800 نقطة في الذاكرة، وليس في سجل الرحلات. إيقاف التطبيق قسرياً قد يُفقد رحلة غير محفوظة.
5. على **أندرويد فقط**: من الإعدادات اقرأ إفصاح المساعد العائم ثم افتح إعدادات إمكانية الوصول وفعّل خدمة DriveProfit يدوياً. يستخدم التطبيق `TYPE_ACCESSIBILITY_OVERLAY` ولا يحتاج إلى إذن إضافي للرسم فوق جميع التطبيقات. تُعرض فقاعة مؤقتة ويمكن لمسها لإخفائها. لتعطيل القراءة أوقف الخدمة من إعدادات النظام.

## الحساب والحدود

- اللترات = كم × استهلاك اللترات لكل 100 كم ÷ 100؛ الكفاءة = 100 ÷ معدل الاستهلاك.
- الصافي التقديري = الأجرة − اللترات × سعر اللتر − الأجرة × نسبة الصيانة ÷ 100. لا تشمل الأجرة المفترضة عمولات منصة أو رسوم طريق ما لم يخصمها السائق مسبقاً.
- تنبيه الوقود يعتمد على الكمية الابتدائية والاستهلاك المقدّر، لا على حساس الخزان. تنبيه السرعة لحد يضبطه المستخدم؛ لا توجد بيانات رادارات أو RPM.
- شاشة البداية تعرض ملخّصاً **توضيحياً** حتى حفظ أول رحلة فعلية، وخريطة نموذجية قبل تحديد الموقع. لا تُحفظ العينات كرحلات. عند التتبّع الحقيقي تعرض Leaflet بلاطات OpenStreetMap؛ يحتاج تحميل الخلفية للإنترنت (ويكشف لمزوّد الخرائط منطقة العرض)، لكن حساب المسافة محلي ومستقل عن البلاطات.
- تُقرأ فقط شجرة النصوص لحزمة `sinet.startup.inDriver`. يدعم المحلل أرقاماً عربية/لاتينية وأسعاراً بالجنيه ومسافات بالكيلومتر. عند غياب البيانات أو ظهور أكثر من مسافة/أجرة، لا يخمّن ولا يعرض نتيجة. لا توجد لقطات شاشة أو نقر تلقائي أو حفظ لنصوص العروض. قد لا تعرض بعض نسخ إندرايف البيانات كشجرة قابلة للقراءة؛ تبقى الحاسبة اليدوية متاحة. يلزم التحقق من النسخة المستهدفة ومن سياسات المنصة وGoogle Play قبل النشر.

## تحديث الوقود

`public/data/fuel-eg.json` هو كتالوج أسعار مؤرخ يتضمن العملة والمصدر والدرجات الثلاث. بدايته [مرجع 17 نوفمبر 2026](https://khalfelhadth.com/159806)، وليس ادعاءً بوجود API حكومي حي. يُقرأ الكتالوج عند تشغيل التطبيق، مع رفض الملفات الناقصة أو الأقدم من آخر مرجع. يحتفظ التطبيق بالسعر المحفوظ عند فشل الاتصال. التعديل اليدوي له الأولوية حتى اختيار «استعادة الأسعار المرجعية».

لتحديث الويب، انشر ملف JSON جديداً بنفس المخطط بعد مراجعة المصدر. لتحديث أندرويد دون إصدار APK جديد، استضف الملف على HTTPS في خادم موثوق يتيح CORS واضبط `VITE_FUEL_FEED_URL` عند البناء. من دون هذا المتغير تستخدم نسخة الهاتف الكتالوج المرفق بها.

## التحقق قبل الاستخدام على الطريق

- اختبارات Node: معادلات الربح والخسارة، رفض القيم غير الصالحة، مسافة GPS وصحة كتالوج الأسعار. اختبارات JUnit للمحلل داخل `android/app/src/test/`.
- اختُبرت الواجهة في Chromium بما يشمل الحاسبة، تغيير المركبة والسعر، بدء/إنهاء رحلة بموقع محاكى، ثبات السجل بعد إعادة التحميل، والتنقل على مقاس الهاتف. هذه الاختبارات لا تعادل اختبار أندرويد الميداني.
- على هاتف متوقف أو بمحاكي GPS: اختبر رفض الأذونات، انقطاع GPS، انتقال التطبيق إلى الخلفية وقفل الشاشة، ثم إنهاء الرحلة وزوال الإشعار. اختبر فقاعة الربح بعرض واضح وخاسر وعروض متعددة وباللغتين. تأكد من معدل البطارية ودقة المسافة وعدم حجب عناصر إندرايف الأساسية.
- لا تُدخل البيانات أو تغيّر الإعدادات أثناء القيادة.
