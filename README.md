# DriveProfit — مساعد الكابتن

تطبيق عربي RTL للسائقين في مصر. الواجهة مشتركة بين معاينة الويب وتطبيق أندرويد باستخدام **React + Capacitor**، مع خدمات Android أصلية بلغة Java للتتبّع وقراءة العروض. يمكن استخدامه كضيف، أو التسجيل بالاسم والموبايل مع موافقة صريحة. الشعار مأخوذ من الصورة المرفقة، وصورة الموتوسيكل توضيحية وليست صورة مواصفات معتمدة للموديل.

## تشغيل الواجهة

يلزم Node.js 22 وnpm.

```bash
npm ci
npm test
npm run dev
```

لبناء ملفات الويب الثابتة: `npm run build` (الناتج في `dist/`). تتطلب واجهة الموقع الجغرافي HTTPS أو localhost وصلاحية من المستخدم. إذا حجبت المعاينة المضمّنة صلاحية الموقع، افتحها في تبويب مستقل. لا يعمل تتبّع الويب بشكل مضمون بعد قفل الشاشة.

## بناء نسخة أندرويد وتثبيتها

يلزم Android Studio وJDK 21 وAndroid SDK 35. الحد الأدنى Android 6 (API 23).

```bash
npm ci
npm run android       # يبني الواجهة وينسخها إلى مشروع Android
npx cap open android # اختر جهازاً ثم Run
```

أو من سطر الأوامر بعد ضبط `ANDROID_HOME`:

```bash
cd android
./gradlew testDebugUnitTest assembleDebug
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

على Windows استخدم `gradlew.bat`. بعد تعديل الواجهة كرّر `npm run android`. يتضمن المستودع سير عمل GitHub Actions لبناء APK تجريبي وتشغيل الاختبارات عند الدفع؛ هذا ليس إصدار متجر موقّعاً. تم بناء نسخة Preview والتحقق من توقيعها في CI، ولم يُجر اختبار ميداني على هاتف فعلي.

## أول رحلة

1. من **مركبتي** اختر الموديل فقط. سعر اللتر، درجة البنزين، معدل الاستهلاك وقواعد الحساب منشورة من الإدارة ولا يستطيع الكابتن تعديلها.
2. أدخل مسافة الرحلة ومسافة الوصول للراكب والأجرة في الحاسبة. أمثلة العروض ومحاكاة الخريطة تدريبية ولا تُحفظ في سجل الرحلات.
3. اضغط **بدء رحلة جديدة** والتطبيق ظاهر. على أندرويد اسمح بالموقع الدقيق، وبالإشعارات على Android 13+. يبدأ `location` foreground service بإشعار مستمر. لا يُطلب موقع دائم ولا تبدأ الخدمة عند إقلاع الهاتف.
4. سجّل الأجرة الفعلية عند **إنهاء الرحلة**. يتوقف GPS وتُحفظ المجاميع محلياً. إعدادات المركبة والأسعار مثبتة عند البداية لحسابات تلك الرحلة. يحتفظ المسار بآخر 800 نقطة في الذاكرة، وليس في سجل الرحلات. إيقاف التطبيق قسرياً قد يُفقد رحلة غير محفوظة.
5. على **أندرويد فقط**: من الإعدادات اقرأ إفصاح المساعد العائم ثم افتح إعدادات إمكانية الوصول وفعّل خدمة DriveProfit يدوياً. يستخدم التطبيق `TYPE_ACCESSIBILITY_OVERLAY` ولا يحتاج إلى إذن إضافي للرسم فوق جميع التطبيقات. تُعرض فقاعة مؤقتة ويمكن لمسها لإخفائها. لتعطيل القراءة أوقف الخدمة من إعدادات النظام.

## الحساب والحدود

- اللترات = كم × استهلاك اللترات لكل 100 كم ÷ 100؛ الكفاءة = 100 ÷ معدل الاستهلاك.
- الصافي التقديري = الأجرة − اللترات × سعر اللتر − الأجرة × نسبة الصيانة ÷ 100. لا تشمل الأجرة المفترضة عمولات منصة أو رسوم طريق ما لم يخصمها السائق مسبقاً.
- تنبيه الوقود يعتمد على الكمية الابتدائية والاستهلاك المقدّر، لا على حساس الخزان. تنبيه السرعة لحد تنشره الإدارة؛ لا توجد بيانات رادارات أو RPM.
- ملخّص الأداء من الرحلات المحفوظة فقط. الخريطة الموسعة تعرض طرقاً وأنهاراً ومدناً إقليمية مرفقة من [Natural Earth](https://github.com/nvkelso/natural-earth-vector) 1:10m (ملكية عامة، وليست خريطة ملاحة). تُحمّل تفاصيل الشوارع من [OpenFreeMap](https://openfreemap.org/) كبيانات متجهية، فيعرف المزوّد منطقة العرض. رفض التحميل لا يوقف GPS ولا يحجب خط المسار.
- تُقرأ فقط شجرة النصوص لحزمة `sinet.startup.inDriver`. يدعم المحلل أرقاماً عربية/لاتينية وأسعاراً بالجنيه ومسافات بالكيلومتر. عند غياب البيانات أو ظهور أكثر من مسافة/أجرة، لا يخمّن ولا يعرض نتيجة. لا توجد لقطات شاشة أو نقر تلقائي أو حفظ لنصوص العروض. قد لا تعرض بعض نسخ إندرايف البيانات كشجرة قابلة للقراءة؛ تبقى الحاسبة اليدوية متاحة. يلزم التحقق من النسخة المستهدفة ومن سياسات المنصة وGoogle Play قبل النشر.

## إدارة الأسعار وقواعد التشغيل (لصاحب المشروع فقط)

افتح **Supabase Dashboard → مشروع DriveProfit → Table Editor → public.drive_policy** وعدّل الصف `id = 1` ثم احفظ. `price_80` و`price_92` و`price_95` بالجنيه لكل لتر، `effective_on` تاريخ الأسعار الظاهر للكابتن، `wear` نسبة من الأجرة، `speed` كم/س، `tank` تقدير ابتدائي باللتر و`sound` لتشغيل صوت التنبيه. لتغيير الاستهلاك أو الأوكتان لفئة بعينها، عدّل `vehicle_overrides` مع الحفاظ على باقي المفاتيح: مثلاً `{"fiat_tipo_14_mt":{"rate":8,"grade":92}}` (مثال توضيحي، وليس قياساً). استخدم معرّف المركبة في الكتالوج. حذف مدخلها يعيدها إلى مواصفاتها المرفقة. إضافة موديلات جديدة من مصدر الكتالوج ثم بناء إصدار جديد.

الدوران `anon` و`authenticated` لهما SELECT فقط؛ لا يوجد حساب إدارة برقم هاتف أو مسار كتابة في التطبيق. لا تمنح العملاء عضوية مشروع الإدارة. يقرأ التطبيق الجدول كل دقيقة وهو ظاهر وعند عودة الاتصال. عند تعذّر القراءة يستعمل آخر سياسة منشورة متاحة محلياً، أو نسخة الإصدار المؤرخة 19 نوفمبر 2026 لأول تشغيل؛ لا يصفها بأنها لحظية. لا يستورد أسعار أو معايرات الإصدارات القديمة من `dp.settings`. لا تُعاد تسعير الرحلات السابقة أو رحلة بدأت بالفعل. خدمة القراءة القديمة من وزارة البترول ليست مصدر النشر في هذا الإصدار.

## التحقق قبل الاستخدام على الطريق

- اختبارات Node: معادلات الربح والخسارة، رفض القيم غير الصالحة، مسافة GPS وصحة كتالوج الأسعار. اختبارات JUnit للمحلل داخل `android/app/src/test/`.
- اختُبرت الواجهة في Chromium بما يشمل الحاسبة، اختيار المركبة واستقبال السعر المنشور، بدء/إنهاء رحلة بموقع محاكى، ثبات السجل بعد إعادة التحميل، والتنقل على مقاس الهاتف. هذه الاختبارات لا تعادل اختبار أندرويد الميداني.
- على هاتف متوقف أو بمحاكي GPS: اختبر رفض الأذونات، انقطاع GPS، انتقال التطبيق إلى الخلفية وقفل الشاشة، ثم إنهاء الرحلة وزوال الإشعار. اختبر فقاعة الربح بعرض واضح وخاسر وعروض متعددة وباللغتين. تأكد من معدل البطارية ودقة المسافة وعدم حجب عناصر إندرايف الأساسية.
- لا تُدخل البيانات أو تغيّر الإعدادات أثناء القيادة.

## كتالوج المركبات وملف الكابتن

- [vehicles_egypt.json](vehicles_egypt.json): الدفعة الأولى كاملة (56 نسخة). انظر [قاموس الحقول، الافتراضات والمراجع](docs/vehicle-data.md). يُصدر البناء الملف نفسه في جذر الموقع للتنزيل البرمجي. يظل الموتوسيكلان الموجودان سابقاً في واجهة التطبيق خارج ملف الدفعة الأولى.
- تمثل الدخلة ملف GIF المرفق محوّلاً إلى WebP متحرك أخف، مع بديل ثابت عند تفضيل تقليل الحركة. لا توجد مهلة انتظار مفروضة. لا تحمل لوحة القيادة مكتبة الخرائط إلا عند احتياجها.
- يحفظ التسجيل بعد الموافقة الاسم والرقم المصري بصيغة E.164 على الجهاز وفي مشروع Supabase مستقل لـDriveProfit. صف لكل جهاز/ملف متصفح، وليس حساب SMS موثقاً. **لا يوجد استعلام يعيد ملفاً بناءً على رقم الهاتف**. ينتج الجهاز سراً عشوائياً (256 بت)؛ يحفظ الخادم بصمته لا قيمته. لا تُنسخ الرحلات أو الإحداثيات إلى جدول التسجيل.
- مخطط قاعدة البيانات والدوال في `supabase/migrations/`. RLS مفعّل ولا يمتلك العملاء صلاحيات مباشرة على الجدول. المفتاح المضمّن publishable مخصص للعميل وليس service-role. يكتب التطبيق في وظيفتي RPC المقيدتين بالإدخال ومفتاح الجهاز فقط.
- إذا تعذر تأكيد الخادم تظهر «بانتظار المزامنة»؛ لا يدعي الموقع أن التسجيل رُفع. يمكن إعادة المحاولة من ملف الكابتن أو عند زيارة لاحقة. اختيار «حذف ملف التسجيل» يحذف السجلين بعد تأكيد الخادم. لا يمسح ذلك سجل الرحلات. مسح تخزين المتصفح أولاً يفقد مفتاح الجهاز؛ يتطلب محو السجل البعيد حينها طلباً إلى مسؤول المشروع والتحقق خارج التطبيق. لا يُنصح بحفظ بيانات شخصية على جهاز مشترك.
- زر تنزيل APK متاح قبل التسجيل. يعتمد `public/data/android-release.json` على أصل مرفوع في GitHub Releases وليس ملفاً فارغاً في المستودع. حزمة `.preview` غير قابلة للتصحيح وموقعة بشهادة **اختبار**، لا شهادة نشر دائمة. قد يتطلب الانتقال بين نسخ الاختبار إزالة القديمة (مما يمسح البيانات المحلية). استخدم هوية توقيع مستقرة ومملوكة للناشر قبل إطلاق عام.
- اختبار الواجهة القابل للإعادة: بعد `npm run build` نفّذ `npm run test:ui` مع Google Chrome مثبتاً أو `CHROME_BIN` يشير إلى Chromium. يحاكي اتصال التسجيل ونقاط GPS وفشل البلاطات؛ لا يرسل أسماء/أرقام الاختبار إلى خادم حقيقي. ويختبر البحث، منع التعديل، عودة المستخدم، الحذف، تقريب وسحب وتوسيط الخريطة وحفظ الرحلة. اختبرت صلاحيات PostgreSQL ووظيفتي التسجيل/المحو أيضاً في معاملة تراجعية دون الاحتفاظ ببيانات اختبار.

### تفعيل خرائط Google داخل الخريطة

خريطة الطرق الرسمية تستخدم **Maps JavaScript API** بالعربية، مع خط الرحلة وإعادة التوسيط. لا تحتاج إذن GPS لمجرد الاستعراض. افتح Google Cloud لمشروعك، فعّل الفوترة وMaps JavaScript API، وأنشئ **مفتاح متصفح** مقيّداً بهذه الـ API وبنطاق النشر المعتمد. ضع `VITE_GOOGLE_MAPS_API_KEY` في `.env.local` أو إعدادات بيئة البناء، ثم أعد البناء. للـAPK التجريبي اضبط GitHub Actions secret بالاسم نفسه قبل البناء؛ هذه النسخة تستخدم WebView وليست Maps SDK for Android، فتحتاج قيود HTTP referrer مناسبة للأصل الفعلي (Capacitor الافتراضي `https://localhost`). لا تستخدم مفتاح خادم أو تزل القيود لمعالجة حجب referrer؛ استخدم الموقع الموثوق إن لم يقبل WebView القيد. المفتاح المضمّن في تطبيق عميل قابل للقراءة، فاضبط قيود الاستخدام والحصص. لا تُرسل المفتاح في المحادثة.

دون مفتاح أو عند فشل تحميل Google يعود التطبيق لخريطة بديلة، ولا يتوقف GPS. زر «فتح في خرائط Google» رابط خارجي لا يحتاج مفتاحاً؛ لا يرسل الإحداثيات إلى Google عبر الرابط إلا عند ضغطه. تعطي واجهة الأذونات إجراءً مختلفاً لحجب geolocation في iframe، أو رفض الموقع من المتصفح، أو رفض أندرويد/الإذن التقريبي، أو إغلاق GPS. لا يُطلب الموقع عند فتح الخريطة، ولا تُعاد محاولة بدء الرحلة تلقائياً.
